# Política de Privacidade — Mazola Effect

Última atualização: 22 de setembro de 2026

O **Mazola Effect** é um app que abre a câmera do seu iPhone/iPad e aplica um filtro de cor negativo em tempo real. Nenhuma imagem, vídeo ou áudio é gravado, salvo ou transmitido para fora do dispositivo.

## Dados coletados

**Nenhum.** O app não coleta, armazena ou transmite dados pessoais.

## Permissões utilizadas

| Permissão  | Uso                                                                                       |
| ---------- | ----------------------------------------------------------------------------------------- |
| **Câmera** | Usada exclusivamente para aplicar o filtro negativo em tempo real. O stream de câmera **nunca sai do dispositivo**. |

Nenhuma outra permissão é solicitada. O app não pede acesso a:

- Contatos
- Localização
- Fotos / biblioteca
- Microfone
- Rede / Internet (na verdade o app não tem nenhum código de rede)

## Terceiros

Não usamos. Não há SDKs de **analytics**, **propagandas** ou **rastreamento**. O app não inclui nenhuma dependência externa — apenas frameworks nativas da Apple (SwiftUI, AVFoundation, CoreImage, MetalKit).

## Crianças

O app é seguro para todas as idades. Não há conteúdo impróprio. Classificação etária na App Store: **4+**.

## Direitos do usuário (LGPD / GDPR)

Como o app não coleta dados pessoais, não há direito de acesso, retificação ou exclusão a ser exercido. Mesmo assim, se você tiver qualquer dúvida, abra uma issue em:

<https://github.com/superaplicativos/MazolaApple/issues>

## Alterações nesta política

Qualquer alteração será publicada neste mesmo arquivo. A data de "Última atualização" no topo será revista.
