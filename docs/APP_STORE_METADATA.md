## Informações do App Review

### Notas para o revisor (PT-BR)

```
Olá!

O Mazola Effect é um app simples que abre a câmera do iPhone/iPad e aplica um filtro de cor negativa em tempo real sobre o feed de vídeo. Ele é usado para visualizar pinturas pintadas em negativo (técnica artística).

Para testar:
1. Toque em "Iniciar Camera".
2. Conceda permissão de câmera quando solicitado.
3. Aponte para qualquer objeto — você verá as cores invertidas em tempo real.
4. Use o botão no topo para alternar entre camera traseira e frontal.
5. Use o switch "Negativo" no rodapé para ligar/desligar o filtro.
6. Toque em "Parar" para encerrar a sessão de câmera.

O app NÃO coleta dados, NÃO tem analytics, NÃO tem anúncios e NÃO faz requisições de rede. Tudo roda localmente no dispositivo. A política de privacidade está em https://raw.githubusercontent.com/superaplicativos/MazolaApple/main/docs/PRIVACY.md.

Não há login. Não há conta. Não há compra in-app.

Obrigado pela revisão!
```
